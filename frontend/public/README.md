# Imagens públicas da ajuda

Adicione `meuperfil.png` nesta pasta para que a Central de Ajuda exiba a captura da
tela `/meu-perfil`. Enquanto o arquivo não estiver disponível, a interface apresenta
um placeholder responsivo, sem imagem quebrada.

## Sons em tempo real

Adicione também os arquivos `notify.mp3`, `whatsapp.mp3` e `telegram.mp3` nesta
pasta. Eles são reproduzidos, respectivamente, para avisos administrativos,
mensagens do WhatsApp e mensagens do Telegram. Se algum arquivo ainda não estiver
disponível, a interface continua funcionando e ignora a falha de áudio.
